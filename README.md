# 3D装箱计算器 (3D Box Packing Calculator)

## 项目概述

这个项目解决了一个实际的3D装箱问题：计算在尺寸为 **13500×2440×2680mm** 的容器内最多能装入多少个尺寸为 **680×680×235mm** 的纸箱。

## 计算结果

### 🎯 核心结果
- **最多装箱数量：627个纸箱**
- **体积利用率：77.18%**
- **总重量估算：1,254kg (1.25吨)**

### 📏 详细布局
- **长度方向：19个纸箱** (19 × 680 = 12,920mm)
- **宽度方向：3个纸箱** (3 × 680 = 2,040mm)  
- **高度方向：11个纸箱** (11 × 235 = 2,585mm)

### 📐 剩余空间
- **长度剩余：580mm**
- **宽度剩余：400mm**
- **高度剩余：95mm**

### 📊 体积分析
- **容器总体积：88.279 m³**
- **单个纸箱体积：0.108664 m³**
- **货物总体积：68.132 m³**

### 主程序文件

- `requirements.txt` - Python依赖包列表

## 技术特点

### 🔍 算法特点
- **多方向优化：** 考虑纸箱的6种可能摆放方向
- **精确计算：** 精确到毫米级的空间计算
- **最优化：** 自动选择装箱数量最多的摆放方案

### 🎨 可视化功能
- **3D立体图：** 完整的3D装箱效果图
- **多视角2D图：** 顶视图、侧视图、前视图
- **详细标注：** 包含尺寸和统计信息

### 📈 分析功能
- **空间利用率计算**
- **剩余空间分析**
- **重量估算**
- **结果导出**

## 算法原理

程序通过以下步骤计算最优装箱方案：

1. **生成所有可能的摆放方向**（6种）
2. **计算每种方向的装箱数量**
3. **选择装箱数量最多的方案**
4. **计算剩余空间和利用率**
5. **生成3D可视化图**

## 扩展性

程序具有良好的扩展性，可以轻松修改：
- 容器尺寸
- 纸箱尺寸
- 可视化样式
- 输出格式

只需要修改 `main()` 函数中的 `container_dims` 和 `box_dims` 参数即可适应不同的装箱需求。
