# 物流货车调度与货物装载优化系统

## 项目简介

本项目为某小型物流企业开发了一套完整的货车调度与货物装载优化解决方案。通过运用3D装箱算法和车辆调度优化技术，在满足所有约束条件的前提下，实现运输总费用的最小化。

## 最优解决方案

经过算法优化计算，得到的最优解决方案为：

- **总运输费用**: 3000元
- **使用货车**: 2辆Type2货车  
- **货物装载**: 100%成功装载所有14件货物
- **空间利用率**: 51.4%

### 详细装载方案

#### 货车1 (Type2 - 12×3×3米)
- 费用: 1500元
- 载重: 5700kg (95.0%利用率) ✅
- 装载: A类4件 + C类5件

#### 货车2 (Type2 - 12×3×3米)  
- 费用: 1500元
- 载重: 4300kg (71.7%利用率) ✅
- 装载: B类3件 + A类1件 + C类1件

**重要修正**: 修复了之前的超载问题，现在所有货车都在载重限制内

## 问题背景

### 货物信息
| 货物类型 | 数量 | 尺寸(长×宽×高) | 重量 | 可旋转 |
|---------|------|----------------|------|--------|
| A类 | 5件 | 3.0×2.0×1.5m | 800kg | 是 |
| B类 | 3件 | 2.5×2.0×2.0m | 1000kg | 是 |
| C类 | 6件 | 4.0×1.5×1.0m | 500kg | 是 |

### 货车选项
| 货车类型 | 尺寸(长×宽×高) | 最大载重 | 使用费用 |
|---------|----------------|----------|----------|
| Type1 | 10.0×2.5×2.8m | 5000kg | 1000元 |
| Type2 | 12.0×3.0×3.0m | 6000kg | 1500元 |
| Type3 | 8.0×2.0×2.5m | 4000kg | 800元 |

## 核心算法

### 算法架构
采用**贪心算法 + 3D装箱算法**的组合方案：

1. **车辆选择**: 基于性价比(载重/成本)排序
2. **装箱策略**: 按体积从大到小贪心装载
3. **位置搜索**: 多层次位置搜索算法
4. **旋转优化**: 自动尝试货物旋转

### 关键特性
- ✅ 满足所有空间和重量约束
- ✅ 支持货物旋转优化
- ✅ 高效的3D装箱算法
- ✅ 全局成本最小化
- ✅ 100%货物装载成功

## 性能分析

### 利用率指标
| 指标 | 货车1 | 货车2 | 平均值 |
|------|-------|-------|--------|
| 载重利用率 | 95.0% ✅ | 71.7% ✅ | 83.4% |
| 空间利用率 | 61.1% | 41.7% | 51.4% |

### 算法复杂度
- **时间复杂度**: O(n × p³) (n=货物数, p=位置数)
- **空间复杂度**: O(n + p³)
- **求解时间**: < 1秒
